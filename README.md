# 🎓 Student Registration Form Automation Using UiPath

### Simplifying Student Registration Through Robotic Process Automation

## 📌 Project Overview

The **Student Registration Form Automation** is an RPA-based project developed using UiPath Studio to simplify and streamline the student registration process.

The automation eliminates repetitive manual data entry by collecting student information through a registration form, validating the entered details, and automatically storing the records in an Excel spreadsheet.

This project demonstrates how Robotic Process Automation can improve efficiency, minimise human errors, and make everyday administrative tasks faster and more organised.

##  Project Objectives

- Automate the student registration process.
- Reduce repetitive manual data entry.
- Validate student information to maintain data accuracy.
- Store registration details systematically in Microsoft Excel.
- Provide instant confirmation upon successful registration.

##  Key Features

📝 **Student Registration Form**  
Provides a simple interface to enter student details, including Name, USN, Email, Phone Number, and Course.

🔍 **Input Validation**  
Checks the entered information to ensure that the required details meet the validation conditions.

📊 **Automated Excel Integration**  
Automatically records the submitted student information in an organised Excel spreadsheet.

✅ **Registration Confirmation**  
Displays a success notification once the registration process is completed successfully.

## ⚙️ Technologies Used

- **UiPath Studio** – Workflow design and automation.
- **Microsoft Excel** – Student information storage.
- **RPA** – Automating repetitive registration activities.

## 🔄 Workflow Process

1. **Form Initialization:** Launches the student registration form.
2. **Data Collection:** Accepts the required student information.
3. **Data Validation:** Verifies the entered details.
4. **Data Storage:** Transfers valid registration details into an Excel spreadsheet.
5. **Confirmation:** Displays a successful registration message.

##  Benefits

- Saves time by reducing manual effort.
- Improves consistency and accuracy in data entry.
- Maintains organised student records.
- Simplifies the overall registration process.
- Demonstrates the practical application of RPA in administrative activities.
